# Basic HTML Website
https://roadmap.sh/projects/basic-html-website

## Goal

Create a basic website using HTML

## Requirements

- [x] Pages: Home page, Projects page, Articles page, Contact page
- [x] The contact page should have a form with fields like name, email, message etc.
- [x] Multiple pages with a navigation bar.
- [x] Structure the content in a way that makes adding styles easy
- [x] SEO meta tags in the head of each page.
